How to Read This Report

  • The health score is a current snapshot. Hotspots and coupling use the last 90 days of Git history when available.
  • Historical Change compares the latest saved Codelens snapshot with the current scan; it is not a health regression check.
  • Health scores identify code that deserves inspection. They do not prove that a specific refactor is correct.
  • Compare reports only when the health model and analysis scope match. Scope or model changes can move the score without a code-quality change.
  • Charts are optional. The complete result remains available in text and tables for offline reading and printing.
